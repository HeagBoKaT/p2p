# АнтиПигвин

P2P-мессенджер для локальной сети (LAN) на WPF/.NET. Без серверов: устройства находят друг
друга через UDP-broadcast, сообщения и файлы идут напрямую по TCP с шифрованием сессии
(ECDH + HKDF, подпись ключом учётной записи).

## Возможности

- Автообнаружение устройств в локальной сети, раздельные списки «Контакты» и «Устройства в сети»
- Текстовые сообщения и передача файлов (drag&drop, вставка из буфера обмена, скорость передачи)
- Очередь отложенной отправки — сообщение уходит само, как только собеседник появится в сети
- Локальная история переписки с настраиваемым сроком хранения
- Сворачивание в трей, уведомления
- Автообновление через GitHub Releases

## Сборка

```bash
dotnet build -c Debug
```

## Публикация одного exe

Параметры однофайловой сборки применяются только к `publish`, не к `build`:

```bash
dotnet publish p2p.csproj -c Release -o publish
```

Результат — `publish/p2p.exe` (self-contained, .NET на целевой машине не нужен).

## Релизы и автообновление

Пуш тега `vX.Y.Z` (версия должна совпадать с `<Version>` в [p2p.csproj](p2p.csproj)) запускает
[.github/workflows/release.yml](.github/workflows/release.yml): собирает `p2p.exe` и публикует
его как GitHub Release. Приложение при старте тихо проверяет `releases/latest` и, если найдена
более новая версия, показывает баннер с кнопкой «Обновить и перезапустить».
